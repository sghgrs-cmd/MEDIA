# 🚀 MEDIA DL — Универсальный веб-загрузчик видео и музыки

Красивое, адаптивное веб-приложение (PWA) для скачивания музыки (MP3) и видео (MP4) с **YouTube, VK Видео, Rutube, TikTok, Дзен** прямо на смартфоне или компьютере.

---

## 📱 Как включить GitHub Pages:

1. Откройте ваш репозиторий: **[github.com/sghgrs-cmd/MEDIA](https://github.com/sghgrs-cmd/MEDIA)**
2. Перейдите во вкладку **Settings** (Настройки репозитория) $\rightarrow$ в меню слева выберите **Pages**.
3. В разделе **Build and deployment**:
   * **Source**: `Deploy from a branch`
   * **Branch**: выберите `main` (или `master`), папку `/(root)`
   * Нажмите кнопку **Save** (Сохранить).
4. Через 1-2 минуты ваш сайт будет доступен по адресу:
   👉 **`https://sghgrs-cmd.github.io/MEDIA/`**

---

## 📲 Как установить на телефон (как приложение):

* **На iPhone (Safari)**: Откройте сайт $\rightarrow$ нажмите кнопку «Поделиться» (квадрат со стрелкой вверх) $\rightarrow$ выберите **«На экран "Домой"»**.
* **На Android (Chrome)**: Откройте сайт $\rightarrow$ нажмите три точки справа вверху $\rightarrow$ выберите **«Установить приложение»** (или «Добавить на главный экран»).

---

## ✨ Возможности:
* 🎵 **Музыка (MP3)**: скачивание аудиодорожки с выбором битрейта (320 kbps HQ, 192 kbps, 128 kbps).
* 🎬 **Видео (MP4)**: скачивание роликов с выбором разрешения (1080p Full HD, 720p HD, 480p, 4K).
* 📋 **Вставка в 1 клик**: автоопределение платформы при вставке ссылки.
* 💾 **Сохранение в историю**: быстрый доступ к ранее загруженным ссылкам.
* ⚡ **Резервные шлюзы**: автоматический переход на резервный сервис, если один из серверов перегружен.
